## 2026-11-14 — MCP Fuzzer: Automated Boundary and Schema Stress-Tester for MCP Servers

> A CLI tool that inspects Model Context Protocol (MCP) server tool schemas and uses Claude to generate adversarial payloads, surfacing unhandled crashes and permission leaks.

**Why now:** As MCP adoption surges across clients like Claude Code and mobile agents, developer discussions highlight that MCP's simplicity leaves server error handling fragile ('MCP Is Dead Simple. And That's Exactly the Problem'). Concurrently, research shows LLM agents fail in complex tasks due to brittle tool response boundaries ('Where LLM Agents Get Stuck Debugging Databases'). Developers need automated fuzz testing tailored to tool-calling protocols.

**Profile fit:** 9/10 — Positions Krithik as an infrastructure developer in the emerging MCP ecosystem rather than just an API consumer, directly extending his existing workshop and Claude SDK expertise.

**Stack:** Python, Anthropic SDK, Typer, Rich, pydantic

**Repo:** `mcp-fuzzer`

- **Day 1** — Build the stdio JSON-RPC client wrapper in Python to auto-discover tool schemas from target MCP servers, then prompt Claude 3.5 Sonnet to generate 15 boundary and malformed test payloads per tool.
- **Day 2** — Execute the test runner against the target MCP server, capture unhandled exceptions or invalid protocol responses, and render a terminal matrix with failure repro commands.

**README hook:** Stress-test your MCP servers before Claude Code crashes on them: single-command adversarial fuzzing for Model Context Protocol APIs.

**Risk:** Parsing non-standard stdio outputs across custom MCP server wrappers; mitigated by adhering strictly to the official MCP JSON-RPC protocol specification over stdio.

## 2026-11-15 — claude-tool-guard: Real-time secret and PII redactor for tool-using Claude agents

> A zero-dependency Python wrapper for the Anthropic SDK that intercepts tool call inputs and outputs to block credential leaks and PII before execution.

**Why now:** Recent high-profile security research revealed major data leaks in AI app builders like Lovable where agents exposed private messages and secrets in production. Simultaneously, discussions around MCP and tool integration emphasize the urgent need for submit guards and permission layers around autonomous agent tool calls.

**Profile fit:** 9/10 — Directly complements Krithik's focus on Claude tool use and workshop materials. It elevates him from a developer who builds agents to one who understands agent safety, security, and enterprise deployment constraints.

**Stack:** Python, Anthropic SDK, Rich CLI, Regex / Presidio

**Repo:** `claude-tool-guard`

- **Day 1** — Build the core interceptor decorator and regex rule engine for credentials (AWS keys, OpenAI/Anthropic keys, JWTs) and common PII (emails, SSNs, credit cards). Integrate directly into Anthropic Python SDK tool call handlers.
- **Day 2** — Add terminal diff visualizer showing sanitized vs raw tool payloads, write CLI launcher (`claude-tool-guard run script.py`), and include interactive demo scripts for workshop integration.

**README hook:** Wrap any Anthropic tool definition in 1 line of code to prevent your agent from leaking secrets or database PII to model contexts and external APIs.

**Risk:** Regex pattern false positives blocking valid non-sensitive strings during streaming responses.
